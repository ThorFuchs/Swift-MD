# SwiftMDODT — experimental OpenDocument Text exporter

Standalone export-only Swift package, sibling of SwiftMDDOCX and SwiftMDEPUB. Swift 6.0 / SwiftGFM 1.1.0; Foundation-only packaging and projection, no app, native GUI, network or file resolution. The existing ViewMarkdown ODT writer was extracted from ThorFuchs/ViewMarkdown PR #68, source blobs f1dc4da4c9590cc6564751b4695a6c7b98de32be, b517501403ec5ed1a2ea8c047188db534a381591 and 0b11cf706454b4d149c665cb0b64c20bbf34829f. Target ODF 1.4 text subset, not full schema conformance or an ODF reader.

Call ODTExporter().render(markdown, title: "Document", options: ODTOptions(), captures: [...]). ODTRaster(destination: "images/figure.png", format: .png, bytes: verifiedBytes) admits already codec-validated bytes supplied by the host. The portable library checks basic framing, format and stored pixel geometry, not full decoder integrity. It never opens paths or URLs. Exact UTF-8 destination identity; repeated references share a package part; distinct destinations remain distinct. Missing, duplicate, unused or over-budget captures fail explicitly. Bytes are kept exactly, including existing metadata: hosts must review disclosure and verify image codecs before supplying them. No automatic EXIF orientation correction; geometry uses stored dimensions. Pictures are inline anchored frames with proportionally bounded geometry (96 px/in, no upscale, max 5.5in × 5in, narrower in tables), alt text and title escaped. PNG/JPEG package parts appear in META-INF/manifest.xml with correct MIME. Resource names are generated, not derived from input paths.

Limits: 1 MiB Markdown, 50,000 AST nodes, depth 32 projection, 128 captures, 16 MiB / 16M pixels each, 48 MiB / 64M aggregate pixels, 4096 image occurrences, 64 MiB output ZIP. Images, headings, paragraphs, lists, GFM tables, quote/code and inline styles; math/Mermaid source rather than rendered graphics, links inert, unsupported HTML/custom nodes/footnotes fail. No macros or remote relationships. A4/Letter, 10/11/12/14 pt, heading page break. Formal OASIS 1.4 RNG validation and native editor compatibility are separate acceptance gates.

Test from this package with swift test. No release or mirror promotion in this PR. References: https://docs.oasis-open.org/office/OpenDocument/v1.4/OpenDocument-v1.4-part2-packages.html and https://docs.oasis-open.org/office/OpenDocument/v1.4/OpenDocument-v1.4-part3-schema.html (draw:frame, draw:image, svg:title, svg:desc).
