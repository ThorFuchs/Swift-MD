# Example gallery

An example combines a GFM table, highlighted Swift, a block equation rendered
to MathML and a Mermaid diagram rendered to SVG. The screenshot was captured
in Chrome with page JavaScript disabled and uses a separate preview stylesheet.

@Image(source: "combined.png", alt: "A table, highlighted Swift code, an equation and a small flowchart rendered by SwiftMD.")

Explore the [complete gallery](https://github.com/ThorFuchs/Swift-MD/tree/main/Examples)
for independently written Markdown sources, actual compiler output, screenshots
and instructions to regenerate them. The preview CSS is not compiler output.
