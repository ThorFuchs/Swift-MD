# Example gallery

These independently written research-style examples combine GFM tables,
inline and display mathematics, highlighted Swift and Mermaid diagrams. Their
data and findings are fictional; they illustrate document rendering, not
scientific evidence. Each screenshot shows actual SwiftMD output in Chrome
with page JavaScript disabled and a separate preview stylesheet.

## Reproducible Analysis of a Small Dataset

@Image(source: "research-reproducibility.png", alt: "A fictional methods paper with equations, sample data, Swift code and an analysis workflow.")

[Markdown source](https://github.com/ThorFuchs/Swift-MD/blob/main/Examples/Markdown/07-research-reproducibility.md) · [HTML output](https://github.com/ThorFuchs/Swift-MD/blob/main/Examples/HTML/07-research-reproducibility.html) · [Word document](https://github.com/ThorFuchs/Swift-MD/raw/refs/heads/main/Examples/DOCX/07-research-reproducibility.docx)

The HTML contains precomputed MathML and SVG. The experimental Word projection
preserves formulas and diagrams as editable source text: it does not create
Office Math or embedded diagram images. Both Word documents come from the same
Markdown as the HTML. Word or another editor controls layout and pagination.

Explore the [complete gallery](https://github.com/ThorFuchs/Swift-MD/tree/main/Examples)
for smaller feature examples and instructions to regenerate and check all
outputs. Preview CSS is not emitted by the compiler.
